# ⏰ Alarm Challenge

**Alarm Challenge** es una aplicación web diseñada para revolucionar la forma en que nos despertamos. En lugar de recurrir al típico tono monótono o a la simple vibración del teléfono, esta plataforma propone una experiencia más dinámica y estimulante para el usuario.

## 🚀 Descripción

El objetivo principal de Alarm Challenge es **romper la rutina del despertar tradicional** e incentivar un estado de alerta real mediante desafíos físicos o mentales. Entre sus funcionalidades, se encuentran:

- 🔍 **Desafíos cognitivos**, como acertijos o retos matemáticos, que ayudan a activar la mente.
- 📸 **Despertares físicos**, que requieren que el usuario se tome una foto para comprobar que realmente está despierto.
- 🔊 **Alarmas sonoras personalizadas**, con control de volumen y repetición, para quienes aún prefieren el método clásico.

De esta forma, Alarm Challenge no solo busca que el usuario apague una alarma, sino que lo **invite a iniciar su día con mayor energía, enfoque y motivación**.

## 🛠️ Tecnologías utilizadas

- **HTML5** — estructura del proyecto
- **CSS3** — diseño responsive y estilos visuales
- **JavaScript (Vue 3)** — lógica de la aplicación y componentes interactivos
- **Poppins** — fuente principal para una apariencia moderna
- **Flexbox & Grid** — sistemas de layout para responsividad

---

## 📸 Características destacadas

- Interfaz dividida en tarjetas (cards) por secciones.
- Flujo paso a paso desde bienvenida hasta creación de alarmas.
- Soporte para múltiples tipos de alarmas.
- Vista de alarmas organizadas por día.
- Estilos responsivos y diseño amigable para dispositivos móviles.
- Botón flotante para agregar nuevas alarmas.
- Notificaciones tipo "toast" para feedback del usuario.

---

## ✅ Cómo usar

1. **Clona o descarga el repositorio.**
2. Abre `index.html` en tu navegador favorito.
3. Navega entre las diferentes secciones usando los botones.
4. Interactúa con los formularios para crear, gestionar o explorar alarmas.

> 💡 No requiere servidor. Todo funciona de forma local en el navegador.
